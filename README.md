# MCU Recap

An interactive catch-up to the MCU before *Avengers: Doomsday*. Browse 116 story pages, character profiles, a universe map, guided paths, and 58 relevant film and show recaps.

[Open the live recap](https://cooper-ganglia.github.io/mcu-recap/)

The site is static and works offline when downloaded with its `assets` folder. See `README.txt` for navigation and content notes, and `image_sources.txt` for image sources.
